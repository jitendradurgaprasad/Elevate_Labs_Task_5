# Task 5: Decision Trees and Random Forests

## Elevate Labs AI & ML Internship

This project implements Decision Tree and Random Forest classification models
for heart disease prediction using the Heart Disease dataset.

## Objective

The objective of this task is to understand and implement:

- Decision Tree Classification
- Decision Tree Visualization
- Overfitting and Tree Depth Control
- Random Forest Classification
- Feature Importance
- Cross-Validation
- Model Comparison

## Dataset

The project uses the Heart Disease dataset stored in:

`data/heart.csv`

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Graphviz
